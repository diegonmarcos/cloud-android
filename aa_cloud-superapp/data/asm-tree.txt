GLOBAL CHROME & SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Drawer (← swipe) ── HomeDrawerFragment
  [Home] → master index
  + prepend actions (home_drawer_prepend)
  All sections listed with 2-level expand

Dynamic Island pill ── toolbar
  Tap → opens Termux (com.termux.nix) per ui.dynamic_island_action

Search sheet ── SearchSheetFragment (scope chips)
  Cloud-Apps    = cloud sections + tiles + home actions
  Phone-Apps    = installed launchable apps (LauncherApps)
  Cloud-Configs = sub-pages + consolidated.json service entries
  Phone-Configs = exported Settings activities

Floating Nav ── FloatingNavService  (always-on-top overlay)

Screensaver  ── ScreensaverService  (configurable, wired to Launcher)

Background   ── BackgroundOrchestrator  (sync, updater WorkManager)
             ── LockScreenAccessibilityService + LockScreenAdminReceiver

In-app Updater ── libs:updater  (OCI/GHCR HTTP API → WorkManager → PackageInstaller)
  Shared signing key across SuperApp / Cloud-Nav / Cloud-Comms / Cloud-IDE

External App Launcher  (extapp: grammar)
  cloud-comms  hub → mail fork / matrix fork / chat fork / dialer fork
  cloud-ide    hub → files fork
  cloud-nav    dedicated Maps/Nav APK (ea_cloud-nav)
  (install fallback: libs:updater fetches APK from installApkUrl if not installed)

Notification Centre ── NotificationStore (in-app feed)
  producers: UpdateWorker · crash reporters

Mode toggle (global, persists ModePrefs)
  Apps   ← everyday front-end view
  Admin  ← cloud ops / infra view
  (affects Infos tile grid, Labs tile grid, section icons, home_groups icons)

App Long-press Menu ── AppLongPressMenu  (context actions on tiles)
