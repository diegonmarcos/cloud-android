# Celestial data credits

Bundled from [d3-celestial](https://github.com/ofrohn/d3-celestial) by Olaf Frohn
(BSD-3-Clause license — see below), which itself credits:

- `stars.6.json` — XHIP: An Extended Hipparcos Compilation (Anderson E., Francis C.,
  2012, VizieR V/137D), stars to magnitude 6.
- `constellations.lines.json` — IAU constellation figures, with line/name adjustments
  by Olaf Frohn; names in other languages from Wikipedia.
- `mw.json` — Milky Way Outline Catalog, Jose R. Vieira.
- `planets.json` — Keplerian Elements for Approximate Positions of the Major Planets,
  JPL (Jet Propulsion Laboratory).

Not a Stardroid port — Stardroid (github.com/sky-map-team/stardroid) is GPLv3, which
would obligate this whole app under GPLv3 if any of its code were reused. d3-celestial
is BSD-3-Clause (permissive, commercial-use-compatible), and its underlying data traces
to VizieR/IAU/JPL rather than any GPL-licensed project.
